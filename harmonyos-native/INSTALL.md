# 鸿蒙应用安装与使用

主应用：示波器-鸿蒙原生-未签名.hap（纯 ArkTS/ArkUI）。
补充应用：示波器-ArkWeb补充版-未签名.hap（包含网页 3D/VR 功能）。

两者已在本机 DevEco SDK 编译通过，当前均为未签名包，不能直接当成已签名安装包使用。

1. DevEco Studio → File → Open → D:\new\shi-bo-qi\harmonyos-native。
2. 等待工程同步，启动 Device Manager 中的模拟器或连接启用开发者模式的鸿蒙设备。
3. 在 Project Structure → Signing Configs 配置适用于目标设备的签名，再点击 Run。
4. 电脑仓库根目录执行 npm run server，后端保持运行。
5. 已连接设备时可执行 hdc rport tcp:3000 tcp:3000；应用服务器地址填 http://127.0.0.1:3000。
6. 在应用内注册、登录，主界面打开“我的实验”保存、恢复或删除实验。

没有服务连接时可以使用游客仿真。原生版账号会话仅保存在应用内存，重启后重新登录即可读取服务器中的实验；服务器地址会在设备上记忆。
网页/ArkWeb 实验为 v1，纯原生实验为 v2；共享账号，参数格式不同，暂不互相恢复。
